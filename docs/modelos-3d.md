# Modelos 3D

O NNN é atualmente composto por imagens 2D. Não há arquivos `.glb`, `.gltf` ou texturas 3D do pacote V8.

Quando um modelo for realmente usado pelo jogo, coloque os arquivos carregados em tempo de execução em `public/models/`; mantenha os arquivos de edição e originais em `outros/arte/`. Não é necessário reservar uma pasta vazia em `public/`.
